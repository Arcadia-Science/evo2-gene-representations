# Figure input data

Every artifact the three experiment runners read in `--figures` mode, and nothing else.
283 files, ~36 MB. Paths mirror the repository layout, so restoring them is one command:

```bash
cp -r pub/figure_data/results .          # or: ln -s "$PWD/pub/figure_data/results" results
bash experiments/exp1_gene_family_geometry.sh --figures   # 3 panels
bash experiments/exp2_composition_controls.sh --figures   # 2 panels
bash experiments/exp3_platypus_steering.sh --figures      # 9 panels
```

`results/` is listed in `.gitignore`, which is why these live under `pub/` instead. They are
copies; the originals stay in the ignored result directories beside the analyses that wrote them.

Per-block files, one set per residual-stream block `blocks0` … `blocks31`:

* `between_family_ot_scores.csv` — Wasserstein rho vs Pfam-JSD / 6-mer / GC (figure 1)
* `evo2_mammal_centroid_distances.csv` — 48x48 family order and centroid distances
* `within_family_speciestree_angular.csv`, `within_family_patristic_angular.csv`,
  `kmer_within_family_correlations_angular.csv`, `within_family_gc_angular.csv` — per-family
  within-ortholog-group rho against each baseline (figures 2, 3)
* `controls/control_between_scores.csv`, `controls/control_within_scores.csv` — control
  preservation per rung, including the paired p3 arms (figure 12)

## Two files are not CSVs

* `stage2_cds_mean/null_distributions.npz` (1.4 MB) — sign-flip and mismatch nulls for figures 6a/6b.
* `stage4_cds_mean_blocks27/generations.jsonl.gz` (9.5 MB) — **never read** in `--figures`; figure 10
  is built from the cached `figures/12b_composition_gene_means.csv`,
  `figures/12c_reference_windows.csv` and `figures/13b_codon_substitution_stats.csv`. It is present
  only because `experiments/exp3_platypus_steering.sh` gates figure 10 on its existence. Point that
  gate at the cache tables instead and this file can be dropped, taking the set to ~26 MB.

`stage1/attrition.csv` and `stage5/rate_vs_direction_shape.csv` are likewise gate-only, but are
small enough to keep as honest inputs.

## One file is regenerated by the run it feeds

`layer_sweep_summaries/mammalian-orthologs-cdsmask-48fam/within_family_vs_layer_wasserstein_angular.csv`
is written by `layer_sweep_summary.py` (figures 1–2) and then read by
`within_family_per_family_grid.py` (figure 3). Running `--figures` therefore rewrites it, so expect
it to show as modified afterwards. It is included so figure 3 can be rendered on its own.
`paired_p3_figure.py` similarly rewrites `paired_p3_protein_vs_nucleotide_paired_stats.csv`, which is
not part of this set.
