# scripts/gpnstar — GPN-Star testing

Home to all GPN-Star–related pipelines. Currently contains:

1. **`test_gpn_star.py`** — verify the GPN-Star checkpoints are used correctly by reproducing the zero-shot ClinVar variant-effect-prediction benchmark.

2. **`run_paralog_human_gene_pipeline_gpnstar.sh`** — run the GPN-Star side of the matched human gene-panel experiment on the same genes/loci used by `scripts/evo2/run_paralog_human_gene_pipeline_evo2.sh`.

Shared math utilities (k-NN, geodesic, Spearman/Mantel) are in
[../geodesic_utils.py](../geodesic_utils.py); figure styling in
[../plot_utils.py](../plot_utils.py). Results are written to
`results/YYYY-MM-DD_gpnstar-<model>/`.

---

## 1. Model verification & ClinVar VEP — `test_gpn_star.py`

Reproduces GPN-Star's zero-shot ClinVar VEP benchmark on `songlab/clinvar_vs_benign`,
scoring each variant by masked log-likelihood ratio and reporting AUROC. Two GPN-Star
models are available: vertebrate (100-way) and mammalian (447-way). This file is also
home of `load_model_compat()`, the transformers ≥4.44 meta-device workaround reused by
the embedding pipeline.

```bash
# Restrict to one chromosome for a quick check (e.g. chr22):
uv run python scripts/gpnstar/test_gpn_star.py --alignments vertebrate --chrom 22

# Single alignment, full ClinVar set:
uv run python scripts/gpnstar/test_gpn_star.py --alignments vertebrate

# Both alignments (default):
uv run python scripts/gpnstar/test_gpn_star.py
```

**Requirements:** needs the multiz MSA zarr — `data/multiz100way.zarr` (vertebrate)
and/or `data/multiz447way.zarr` (mammalian); download via
`python scripts/gpnstar/download_msa.py vertebrate` (~42 GB). Model checkpoints are
auto-downloaded to `models/`. Published GPN-Star AUROC on this set is ~0.89–0.91.
Outputs (`vep_scores.csv`) go to `results/YYYY-MM-DD_gpnstar-<model>/`.

## 2. Matched Human Gene Pipeline

Tests whether **GPN-Star** embeddings of the matched human Panel-1 loci cluster by
gene family, via geodesic distances on a k-NN manifold, compared against the same
human baselines used for the Evo2 matched-human run.

**Family selection (HGNC-based).** Each family is pulled from a curated, orthology-aware
**HGNC gene group** rather than a shared-domain bag, so the latent-space question is about
*gene-family* learning, not domain recognition. Six families: globins, opsins, olfactory
receptors, cytochrome P450 (the advisor's core set), plus HOX and RAS GTPases as
well-separated positive controls. Membership is generated by `gene_families.py build-human-paralog`
(the shared `scripts/gene_families.py`) → `families_data.json` (191 human genes; ORs subsampled to 40 of ~416).

Because GPN-Star is **genome-anchored** (it embeds an hg38 locus + its multiz-100way MSA
stack), per-family N is bounded by the human paralog count, and only human nuclear loci are
reachable. This maximises *within-family* depth (~3.7k within-family pairs vs ~140 in the
old 10-family set) at the cost of a smaller between-family matrix. Two advisor-proposed
families are cross-kingdom by nature and are deferred to **Evo2**: heme-copper oxidase (the
human catalytic subunit is mitochondrial, and HGNC group 643 is the non-homologous complex-IV
assembly) and the bacterial/myoglobin breadth of the globin family.

**Pipeline order:** `download_msa.py` → `embed_and_geodesic.py` →
`layer_selection.py --panel human` → shared human baselines → figures. These are
chained by `run_paralog_human_gene_pipeline_gpnstar.sh`. The matched gene/locus set comes
from `test_sample_human_genes.load_matched_panel()`, the same loader used by the
Evo2 human runner.

| File | Purpose |
|------|---------|
| `download_msa.py` | Download the vertebrate (100-way) or mammalian (447-way) MSA zarr for GPN-Star, or build a small synthetic one for smoke-testing. |
| `embed_and_geodesic.py` | Embed each matched human transcript span with GPN-Star, cache all hidden states, and write a run dir (geodesic + family-centroid distances) at the selected layer. Also the shared embedding-helper library (model loading, hg38 transcript-span coords, MSA-window tiling, `embed_gene_multiwindow`) reused by `layer_sweep.py` and the MSA controls. |
| *(ground-truth baselines)* | The shared `../baselines/` scripts (Pfam-JSD, k-mer, sampled CDS seq-identity, protein-alignment patristic/seq-id, between-family). The legacy inline paralog baselines + standalone embedder are archived in `deprecated/gpnstar_*_legacy.py`. |
| `../gene_families.py` | Shared single source of truth for gene families (both models): `build-human-paralog` generates `families_data.json` from HGNC gene groups; provides `family_members`/`family_order`/`family_colors` + `PFAM_ACCESSIONS`. |
| `gpnstar_visualization.py` | Figures (`--figures`): Figure 2 (family-level geodesic vs. Pfam JSD / seq-identity / PANTHER) and within-family geodesic vs. paralog/seq-identity comparisons. |
| `run_paralog_human_gene_pipeline_gpnstar.sh` | Sequential background runner for the matched human GPN-Star job: MSA check → human sweep → layer selection → run dir → shared baselines → figures. |

Results are written to `results/YYYY-MM-DD_gpnstar-<model>/`.

The one-time **~42 GB MSA download** is the main upfront cost; GPN-Star is a 200M-parameter
model. (Per-step wall-clock times to be filled in from a clean run.)

**Also here (not part of the chained pipeline):** `download_gene_sequences.py` — a
standalone tool to download CDS for a gene family from NCBI RefSeq and deduplicate with
MMseqs2. NCBI requires a contact email for Entrez, so **set `NCBI_EMAIL` before running**
(requests with no email are throttled and eventually blocked):

```bash
export NCBI_EMAIL="you@example.com"
```

Near-duplicate clustering also needs the `mmseqs` binary on your PATH (install via
`conda install -c bioconda mmseqs2`); without it the script still runs and just keeps
the near-duplicates. See the optional-tools note in `pyproject.toml`.
